# 公勝稽核表（網頁 App）

公勝「業務中心每月自行管理檢核表」自動填寫工具。選好月份、填入事業部會議日期，按一下「自動填寫」，就會從抽查名單隨機挑人、配上當月上班日填好整份檢核表，再匯出制式 **Word** 檔，直接列印交給總公司。

Windows、Mac、手機的瀏覽器都能用，不需要安裝任何軟體；也可以「安裝」成桌面上的 App，第一次開啟後沒有網路也能使用。

## 第一次使用：建立抽查名單

本網站**不內建任何人員名單**。第一次打開時，請先到「名單管理」：

1. 在「貼上名單」貼上同仁名單，一行一人，格式為「事業部 姓名」或只寫「姓名」（也可用逗號或 Tab 分隔，可直接從 Excel 複製兩欄貼上；「姓名[編號]」的編號會自動去掉）。
2. 或按「從 .txt／.csv 檔匯入」，選擇名單檔（支援 UTF-8 與 Excel 存的 Big5 CSV）。
3. 按「加入名單」或「取代整份名單」。

至少需要 5 人才能自動抽人。名單之後可以在同一頁增刪、搜尋。

## 每月怎麼用

1. 「① 基本設定」填業務中心（會記住）、選檢核年月，加入事業部會議日期（可多個）。
2. 有休假或不算上班的日子，可在日曆上點一下排除。
3. 按「✨ 自動填寫」：日期都會落在上班日（已內建人事行政總處 115、116 年辦公日曆），同一個月不會重複抽到同一人，也會避開上個月（名單夠多時避開前兩個月）抽過的人；填寫報表時間自動帶當月最後一個上班日。
4. 右側每一格都可以直接修改，不滿意可按「🎲 重新隨機」。
5. 按「⬇︎ 匯出 Word 檢核表」，檔案會存到瀏覽器的「下載」資料夾。若沒出現，可按畫面上的「再次下載」或「備用下載」。

## 安裝成 App

| 裝置 | 做法 |
|---|---|
| Windows／Mac 的 Chrome、Edge | 按頁面上方的「安裝 App」，或網址列右側的安裝圖示 |
| iPhone／iPad（Safari） | 點「分享」→「加入主畫面」 |
| Mac Safari | 選單「檔案」→「加入 Dock」 |

安裝後會出現獨立的 App 視窗和圖示，開過一次之後沒有網路也能使用。

## 資料與隱私

- 所有計算和 Word 產生都在使用者自己的瀏覽器內完成，不會上傳到本站或任何伺服器。
- 抽查名單、抽籤紀錄、會議日期與草稿只存在這台電腦的瀏覽器裡（localStorage），換電腦或換瀏覽器不會同步。在共用電腦上用完，可在「名單管理」按「清空整份名單」。
- 本站網址公開，但不含任何同事的姓名或個人資料；內建的只有空白的檢核表格式和國定假日資料。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App（畫面、上班日計算、抽人、Word 產生都在這一個檔案裡） |
| `manifest.webmanifest` | App 名稱、圖示、獨立視窗等安裝設定 |
| `sw.js` | Service worker，快取本站檔案供離線使用 |
| `icons/` | App 圖示（192、512、maskable 512、Apple 觸控圖示、網頁小圖示） |
| `.nojekyll` | 讓 GitHub Pages 原樣發布檔案 |

## 發布到 GitHub Pages

1. 把這個資料夾裡的所有檔案（含 `.nojekyll`）放到 GitHub repo 的根目錄。
2. repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後即可用 `https://<帳號>.github.io/<repo名稱>/` 開啟。

所有路徑都是相對路徑，放在任何子目錄都能運作。Service worker 只在 `http(s)` 網址下啟用；直接雙擊 `index.html` 開啟也能使用，只是沒有安裝與離線功能。

## 更新版本

修改內容後，請把 `sw.js` 的 `VERSION` 和 `index.html` 裡的 `APP_VERSION` 改成新的版本號（例如 `1.0.1`）再發布。使用者下次連網開啟時會自動抓到新版、清掉舊快取；頁面顯示「有新版本」時重新整理一次即可。

國定假日資料目前內建 115、116 年；其他年份只排除週六日，請手動在日曆上排除假日。
